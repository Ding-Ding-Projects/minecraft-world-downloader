Download the world as you play

Everything it does

All of it, not a highlight reel. A feature that ships and never appears here is undocumented in practice, however good its code is.

World downloaderA proxy between your client and the server that writes every chunk you are sent straight to a world folder.
Live map viewerBrowse the tiles a downloaded world produces, with layers, a coordinate readout and markers.
Container managerStart, stop, restart and read logs for the containers on a connected host.
Chat captureRecord server chat against your own match rules, stored locally and exported only when you ask.
Browser-style tabsDocked to any edge, left by default, with pinning, groups, an overflow surface and four separate tab searches.
Regex builder everywhereEvery search field, dropdown and right-click menu carries a filter and its own anchored regular-expression builder.
Per-element appearanceRight-click anything for Edit appearance. Colour, typography, shape, spacing and every state, saved as presets you can export.
Infinite colour pickerA continuous picker with a translator across fourteen formats, a gamut warning and a live contrast readout.
Word-depth font pickerFamily, size, weight, every decoration, case, position, colour, spacing, alignment and direction.
Command paletteCtrl+Shift+F reaches every command, destination, setting and article, with live controls rendered inline in the results.
Three language modesEnglish, playful Hong Kong Cantonese, and a bilingual mode that does not crowd the layout.
Funny levels 1 to 5Independent per language. Voice changes completely; the facts in a warning never do.
Spoken narratorOff by default. Selectable voice, rate and pitch per narrated language, with a serialized queue that never overlaps.
Emoji toggleDecoration in dialogs and message boxes only, never in a control label or an accessible name.
School modeOne shared switch across every app, applied live, hiding the playful capabilities entirely rather than merely disabling them.
Personal vocabularyUpload a local JSON file to rewrite wording. Local only, never uploaded, and absent until you supply a valid file.
Scheduled settingsSchedule language, theme, density and every other appearance value by date, time and weekday, or from a local source.
Local version historyEvery change to settings, markers, profiles and rules is snapshotted in a local repository. Restore appends, never rewinds.
Changelog viewerEvery released version, filterable by date, searchable, exportable, with each entry linking the commit that made it.
Non-blocking notificationsCorner-anchored toasts with a reviewable notification centre. Modals are reserved for real decisions.
Destructive-action gateTwo independent keys and a full-range slider, with an emergency exit that never leaves the screen.
Element locksLock any rendered element behind a password or a one-time code. A for-fun lock, and it says so.
Support TicketsThe lock recovery route, dressed as a support desk, whose resolution opens your own data folder.
Built-in authenticatorStandard TOTP for your own accounts, with QR pairing. Local, no account, no sync.
Export in every formatJSON, YAML, TOML, XML, CSV, TSV, Markdown, HTML, SQL and archives, with any lossy conversion disclosed first.
Bulk actions everywhereEvery list, table and grid, including the notification centre and the history panel.
File converterA local converter with a categorized adapter catalog that lists what it cannot do as plainly as what it can.
Ollama suite managerBrowse the full model catalog, judge hardware fit conservatively, pull in batches and chat locally.
App logo customizationPresets plus your own local image, converted locally into every size the interface needs.
External editor handoffOpen any export or project folder straight in Visual Studio Code as a workspace root.
Automatic updatesChecked in the background, staged quietly, and installed only when you choose to restart.
AccessibilityKeyboard reachable, visible focus, correct roles and names, contrast held in both themes, reduced motion respected.
Offline documentationEvery article bundled into the build and readable inside the app with no network.
A small helloA one-in-ten chance at launch of a dim sum dish, named in English and Traditional Chinese.

This site
No analytics. No tracking. No third-party requests.
Every asset is served from this origin.
Settings are stored in your own browser.

The download button uses the immutable release asset URL from a validated release manifest, and states the version, the platform, the size and the date. Until publication is verified it is absent rather than pointing at a guessed or candidate URL — a download button that 404s is worse than no button.

The unsigned warning is on the button, not buried in a FAQ. Code signing is out of scope for this project, so Windows will show an unknown-publisher warning. Saying so beside the download is the difference between a user who expects it and a user who assumes the file is malicious.

No CDN, no remote font, no analytics, no third-party request. Every asset is bundled and served from this origin, exactly as the application makes no network request of its own. A documentation site that phones home while describing a privacy-respecting tool undermines the claim it is making.

This page carries the whole contract, not a marketing subset. Language modes, funny levels, the theme switch, the tabbed navigation, the search with its anchored regex builder, the appearance editor, element locks, the command palette on the same Ctrl+Shift+F. "It is only a landing page" is not an exemption.
