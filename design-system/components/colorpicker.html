Continuous, not a swatch grid. The wheel and the saturation-value field cover the whole space, and every value is also enterable as a number. Swatches, recents and the eyedropper are conveniences layered on top of that — they never replace it, because a finite palette cannot express a colour the user actually wants.

Alpha is preserved across every conversion. Translating to a format that cannot carry alpha states what is being dropped before it happens. That is the general rule for this product: no export or conversion silently loses a field.

CMYK is device-dependent and labelled as such. Without a colour profile it is an approximation, and presenting it as an exact value is a promise the picker cannot keep on any particular printer.

The picker themes itself. Its own dialog, its labels and its chrome obey the same appearance system as everything else, and each element in it carries Edit appearance… like any other. A theming control that cannot theme its own dialog is incomplete.
