# Roadmap

This roadmap is factual and limited to the Windows desktop manager while the current desktop-only scope override is active.

## Completed milestone: desktop safety and shared foundations

- Current-user DPAPI encryption for the console password, including migration from legacy plaintext settings.
- Redaction of password/token/secret/key Docker environment arguments from the in-app command log.
- Defensive YAML scalar encoding for generated Compose configuration.
- Persistent M3-styled tabs for Downloader, Settings, Regex builder and Notifications.
- Persistent English, playful Hong Kong-style Cantonese and bilingual modes with independent 1–5 funny levels.
- Bounded local .NET regex builder with guided constructs, flags, syntax feedback, live matches/captures, copy/export, and Settings-search integration.
- Corner notifications plus reviewable in-session history; external-editor detection/selection/launch.
- Opt-out 1% startup dim-sum delight using three bundled local images and dish-specific alt text.
- Ten desktop regression tests and Lowlevel MCP headless runtime captures.
